# Adicta

The Adicta design-study website. Static HTML, CSS and artwork; no build step required.

## Local preview

Open `index.html` in a browser, keeping the other files and `assets/` beside it. Click the floating corn to invert the page colours. The site adapts to mobile screens and respects reduced-motion settings.

## GitHub Pages

Publish from the `main` branch and `/ (root)` in Settings → Pages.

Intended Pages address: https://maxwoodworks.github.io/adicta/

## Custom domain

`adicta.nz` can be connected after registration. It is not configured here yet, so the Pages address remains usable.

## Artwork

Website artwork is derived from the supplied Adicta Photoshop and Illustrator files. Display lettering is outlined; no font software is included. Original editable design documents and local backups are not included in this public website repository.
